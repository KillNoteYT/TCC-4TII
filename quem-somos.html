Sobre o iTDesigns

Projeto desenvolvido individualmente por Mateus Pereira Camargo como Trabalho de Conclusão de Curso do Técnico em Informática Integrado.

Proposta

O projeto foi criado para praticar a construção de páginas web adaptáveis a diferentes dispositivos. O foco principal foi melhorar a responsividade entre celular, tablet e desktop e aprofundar o uso do Bootstrap.

A versão original foi desenvolvida em aproximadamente nove meses, utilizando HTML, CSS, Bootstrap e JavaScript em interações demonstrativas.

Refatoração para portfólio

Em 2026, o projeto foi revisitado para corrigir problemas da implementação acadêmica sem descaracterizar sua proposta. A refatoração reorganizou HTML e CSS, padronizou o Bootstrap, corrigiu caminhos quebrados, melhorou a semântica e eliminou posicionamentos rígidos que prejudicavam a responsividade.

Tecnologias

  • HTML5 semântico
  • CSS3
  • Bootstrap 5
  • JavaScript

Foco técnico

Responsividade, grid, componentes do Bootstrap, organização visual e manutenção de um projeto Front-end multipágina.
