# TCC-4TII — iTDesigns

> Projeto de desenvolvimento web desenvolvido individualmente como Trabalho de Conclusão de Curso durante a formação técnica em TI, com foco na criação de interfaces responsivas e no aprofundamento do uso do Bootstrap.

🔗 **Aplicação:** [itdesigns.vercel.app](https://itdesigns.vercel.app/)

---

## 📌 Sobre o projeto

O **iTDesigns** é um projeto de desenvolvimento web criado como Trabalho de Conclusão de Curso (TCC) durante minha formação técnica em Tecnologia da Informação.

O projeto teve como principal objetivo **aprimorar a construção de interfaces responsivas entre diferentes dispositivos**, explorando os recursos oferecidos pelo **Bootstrap** em conjunto com HTML, CSS e JavaScript.

O desenvolvimento partiu de um protótipo criado anteriormente durante a formação e evoluiu para uma versão mais completa, com diferentes páginas, navegação entre seções e modelos de sites.

---

## 🎯 Objetivos

- Desenvolver uma aplicação web responsiva;
- Aprimorar a utilização do Bootstrap;
- Praticar a construção e organização de interfaces com HTML e CSS;
- Explorar a adaptação de layouts para diferentes tamanhos de tela;
- Aplicar JavaScript em funcionalidades de interação;
- Consolidar conhecimentos adquiridos durante a formação técnica em TI.

---

## 🚀 Funcionalidades

- Página inicial com apresentação do projeto;
- Página de login com validação utilizando JavaScript;
- Página "Quem Somos";
- Página de contato;
- Navegação entre diferentes páginas;
- Apresentação de modelos de sites;
- Layout responsivo para diferentes dispositivos;
- Utilização de componentes e classes responsivas do Bootstrap.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação das páginas;
- **CSS3** — estilização e personalização das interfaces;
- **JavaScript** — interações e lógica da aplicação;
- **Bootstrap** — framework utilizado na construção e responsividade das interfaces;
- **Bootstrap Icons** — utilização de ícones na interface;
- **Vercel** — hospedagem da aplicação.

---

## 📱 Responsividade

Um dos principais focos do projeto foi trabalhar a adaptação das interfaces para diferentes dispositivos.

Durante o desenvolvimento, foram explorados recursos de responsividade do Bootstrap e técnicas de CSS para adaptar a apresentação dos elementos de acordo com o tamanho da tela.

O projeto foi pensado considerando principalmente:

- 📱 Dispositivos móveis;
- 📟 Tablets;
- 💻 Desktops.

Essa abordagem permitiu estudar na prática a construção de interfaces capazes de manter sua estrutura e usabilidade em diferentes resoluções.

## 🔄 Evolução do projeto

O desenvolvimento do TCC teve como base um protótipo criado anteriormente durante a formação técnica.

O protótipo serviu como etapa inicial para experimentação da estrutura visual e da navegação. A partir dele, o projeto foi desenvolvido e aprimorado, com maior atenção à **responsividade**, à organização das páginas e à utilização dos recursos disponibilizados pelo **Bootstrap**.

Essa evolução permitiu transformar uma primeira proposta de interface em uma aplicação web mais completa.
