iTDesigns

Projeto desenvolvido como Trabalho de Conclusão de Curso durante a formação técnica em TI, com foco na criação de uma aplicação web para apresentação e comercialização de serviços de desenvolvimento de sites.

/// Evolução do projeto

O projeto teve início a partir de um protótipo desenvolvido durante a formação. A versão inicial foi utilizada como base para definição da interface e experiência de navegação. Posteriormente, a aplicação foi expandida para o projeto de TCC, incorporando novas páginas, fluxo de login, navegação entre diferentes modelos de sites e funcionalidades implementadas com JavaScript

// Objetivo do trabalho

Criar uma solução para startup's de caixa baixo a conseguir dar o primeiro passo digital;

// Funcionalidades

- Página responsiva e atraente;
- Implementação de fluxo de login simulado com JavaScript.
- Implementação de carrossel, navbars e etc.

// Tecnologias utilizadas

- HTML
- CSS
- Bootstrap
- JS
- Vercel
