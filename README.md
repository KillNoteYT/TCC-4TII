# iTDesigns — TCC-4TII

Projeto individual desenvolvido como Trabalho de Conclusão de Curso do Técnico em Informática Integrado, com foco em **responsividade entre dispositivos** e aprofundamento do uso do **Bootstrap**.

> A versão atual é uma refatoração para portfólio do projeto acadêmico original de 2024.

## Objetivo

Construir uma aplicação web multipágina adaptável a celular, tablet e desktop, praticando HTML, CSS, Bootstrap e interações simples com JavaScript.

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript

## O que foi refatorado

- Padronização da estrutura HTML e do Bootstrap;
- HTML mais semântico e acessível;
- Correção de caminhos e links quebrados;
- Remoção de IDs duplicados e estilos rígidos;
- Substituição de regras que sobrescreviam classes nativas do Bootstrap;
- Responsividade reestruturada com grid, Flexbox, `picture` e CSS fluido;
- Login reposicionado sem coordenadas fixas e identificado como demonstração Front-end;
- Validação de formulários e feedback via JavaScript;
- Remoção de dados de contato pessoal hardcoded do fluxo demonstrativo;
- Conteúdo comercial reposicionado como apresentação de portfólio.

## Estrutura

```text
.
├── index.html              # login demonstrativo
├── pagina-inicial.html     # página principal
├── quem-somos.html         # contexto do TCC
├── contato.html            # formulário demonstrativo
├── site-pessoal2.html      # modelo de site pessoal
├── site-corporativo.html   # modelo de site empresarial
├── estilos.css             # estilos gerais
├── styles.css              # estilos do login
├── script.js               # interações e validações
└── img/                    # imagens do projeto
```

## Login demonstrativo

Vale ressaltar que este projeto **não possui autenticação real nem backend**. O login existe apenas para demonstrar manipulação de formulário e JavaScript no front-end.

- Usuário: `usuario`
- Senha: `senha`

## Evolução

A primeira versão foi desenvolvida durante a formação técnica. Em 2026, o projeto foi revisitado para aplicar melhores práticas aprendidas posteriormente, preservando sua identidade e o foco original em responsividade e Bootstrap.
